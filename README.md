# 🌸 Flower Species Classification Using Machine Learning

This project classifies flower species using a **Machine Learning classification model** trained on the **Iris dataset**.  
The dataset is stored in a **SQLite database** and used to train a **Logistic Regression** model.

---

## 📌 Project Type
- **ML Category:** Basic Machine Learning
- **Task:** Classification
- **Algorithm Used:** Logistic Regression
- **Dataset:** Iris Dataset

---

## 🎯 Objective
To predict the species of a flower based on its physical features such as sepal length, sepal width, petal length, and petal width.

---

## 🌼 Flower Species
- Setosa  
- Versicolor  
- Virginica  

---

## 🗄️ Database Used
- **SQLite**
- Data is stored and retrieved from a local database file (`flowers.db`)
